    Часть рисунков в этих шаблонах взята из публичных архивов. Эти наборы зачастую были очень неполны и не имели в комплекте html файлов. Все html файлы написаны с нуля. Для завершения наборов я добавил, по меньшей мере, половину рисунков. Частично изменив существующие рисунки и во многих случаях, создав новые. Некоторые шаблоны создавались полностью с нуля, они помечены знаком авторского права.

    Совершенно ясно, что я потратил на создание этих шаблонов немало времени. Можете использовать их свободно для любых программ. Единственное требование, не изменять кнопку Link и ссылку внизу каждого шаблона. Они ссылаются на мой сайт, так что другие тоже смогут найти эти шаблоны.

По требованию можно получить исходные наборы, которые можно использовать без этих ограничений.

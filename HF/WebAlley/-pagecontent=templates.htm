  основной
Простая текстовая страница без графики и украшений.

загрузить этот шаблон

синие полосы
В основу этой страницы положена таблица html, создающая синие полосы. Полосу слева можно использовать для размещения навигационной панели. Графика не используется.

загрузить этот шаблон

фиолетовый
Различные оттенки фиолетового, светлый фон, текст выровнен по левому краю. Эта страница тоже построена на таблицах и тоже не использует графику.

загрузить этот шаблон

оранжевый
Оранжевый шаблон использует таблицы несколько иначе. Оранжевая страница как бы парит над сине-зеленым фоном.

загрузить этот шаблон

гурман
Украшена пищевыми продуктами и предназначена для гурманов. Компоновка этой страницы управляется таблицами. Рисунки позаимствованы из шаблона AOL и могут использоваться бесплатно. В ЗИПе вы найдете дополнительные рисунки: несколько кнопок и другой фон.

загрузить этот шаблон

собаки
Собака - друг человека. Этот шаблон для тех, кто любит собак. Идеален для типичной страницы 'Моя собака'. НЕТ. Рисунки тоже позаимствованы из шаблона AOL и могут использоваться бесплатно. В ЗИПе вы найдете некоторые дополнительные кнопки.

загрузить этот шаблон

светло-синий
Элегантные светло-синие элементы на белом фоне, центрированный текст.

загрузить этот шаблон

любопытный
Любопытный инспирирован рисованным человечком, часто используемым в простой графике. Нижняя часть страницы немного расширена и образует его ноги. Сама страница делает из человечка что-то типа бутерброда.

загрузить этот шаблон

дизайн
Элементы расположены на белом фоне, текст выровнен по левому краю. Если вы ищете ясный и простой современный дизайн, то этот шаблон вам понравится.

загрузить этот шаблон

черный
Простые цветные элементы на черном фоне, центрированный текст.

загрузить этот шаблон

охра
Элементы цвета охра на белом фоне, центрированный текст. Для полос используется простой объемный эффект, типа того, что применяется на рабочем столе MS Windows.

загрузить этот шаблон

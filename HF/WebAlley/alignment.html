заключение 		      Расположение содержимого ячейки можно контролировать с помощью нескольких атрибутов выравнивания. В таблице ниже вы видите стандартное выравнивание по левому краю, как на обычной веб странице. Выравнивание по вертикали происходит иначе, по умолчанию выполняется выравнивание по центру ячейки. Если содержимое одной ячейки выше, чем в другой, то более низкое содержимое смещается вверх.

<TABLE BORDER="1" WIDTH="400">
<TR>
<TD>содержимое ячейки</TD>
<TD>содержи-<BR>мое<BR>ячейки</TD>
</TR>
</TABLE>

    Горизонтальное выравнивание определяется атрибутом ALIGN тега TD. Выравнивание по левому краю происходит по умолчанию, поэтому нет необходимости его указывать. Этот атрибут используется на этой странице для центрирования навигационной полосы.

<TABLE BORDER="1" WIDTH="400">
<TR>
<TD ALIGN="LEFT">ячейка</TD>
<TD ALIGN="CENTER">ячейка</TD>
<TD ALIGN="RIGHT">ячейка</TD>
</TR>
</TABLE>

ячейка ячейка ячейка

    Вертикальное выравнивание содержимого определяется атрибутом VALIGN. Выравнивание по центру можно не указывать, поскольку оно выполняется по умолчанию. Советую всегда устанавливать выравнивание по верху ячейки, чтобы избавить себя от сюрпризов при изменении содержимого.

<TABLE BORDER="1" WIDTH="400">
<TR>
<TD>я<BR>че<BR>й<BR>ка</TD>
<TD VALIGN="TOP">ячейка</TD>
<TD VALIGN="MIDDLE">ячейка</TD>
<TD VALIGN="BOTTOM">ячейка</TD>
</TR>
</TABLE>

    Меню в навигационной полосе в левой части этой страницы выровнено по верху с помощью атрибута VALIGN. На некоторых страницах меню может быть больше текста самой страницы. Во избежание проблем, я всегда устанавливал вертикальное выравнивание текста по верху.
    Атрибуты выравнивания можно использовать также в тегах TR и TABLE. В этом случае они определают выравнивание для всей строки или таблицы. Причем параметры ячейки преобладают над параметрами строки, а параметры строки преобладают над параметрами таблицы.

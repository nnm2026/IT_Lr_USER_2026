<FRAMESET>...</FRAMESET>
Начинает и заканчивает набор фреймов. Заменяет собой тело обычное страницы.
FRAMEBORDER="..."
FRAMESCPACING="..."
BORDER="..."
Эти три атрибута отключают границы во всех браузерах. Значение должно быть равно нулю.
ROWS="..."
Устанавливает количество и размер фреймов по горизонтали. Значение устанавливается либо в пикселях, либо в процентах, либо с помощью звездочки. Последняя захватывает все оставшееся место.
COLS="..."
Тоже самое, что и ROWS, только по вертикали.

<FRAME>
Определяет отдельные фреймы в наборе фреймов. Должен быть внутри тегов FRAMESET.
SRC="..."
Определяет веб страницу, которая будет загружена во фрейм. Должна быть указана достоверным адресом URL.
NAME="..."
Дает имя фрейму, которое будет использоваться в ссылках с помощью атрибута TARGET.
NORESIZE
Запрещает пользователю изменять размер фрейма.
MARGINHEIGHT="..."
Определяет растояние между содержимым фрейма и его границей по вертикали. Установите его значение равным нулю для сохранения места и для объединения соседних фреймов.
MARGINWIDTH="..."
Тоже самое, только по горизонтали.

<NOFRAMES>...</NOFRAMES>
Содержат альтернативную страницу для браузеров, которые не поддерживают фреймы. Должны быть расположены между тегами FRAMESET.

TARGET="..."
Атрибут, который используется в ссылках на фреймовой странице. Позволяет ссылке открываться в другом фрейме, определяемым с помощью атрибута NAME. Существуют зарезервированные имена, которые можно узнать по символу подчеркивания.
<A HREF="page.html" TARGET="имя">страница</A>.
_blank показывает ссылку в новом окне браузера
_self показывает ссылку в том же самом фрейме, где и ссылка
_parent показывает ссылку в родительском окне или наборе фреймов
_top показывает ссылку на полностью открытом окне браузера

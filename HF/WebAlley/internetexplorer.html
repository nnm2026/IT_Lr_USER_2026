      Когда я начал изучать реализацию DHTML в IE 4, я сразу увидел, насколько она шире, чем в NS. DHTML в IE полагается не на один единственный тег (как в NS), а скорее на новые объекты и свойства, происходящие из обычных тегов HTML, таких как, например, <div> и <table>. Эта реализация DHTML значительно мощнее, но и освоить ее совсем не так просто.

Объект style в IE 4
    Теперь все элементы HTML в IE 4 поддерживают объект style (стиль), который, в сущности, является "динамическим" объектом и используется для управления внешним видом и поведением элемента. Подобно тегу <layer>, элементам можно присвоить атрибут "id", который затем используется для обозначения элемента в скриптах. Например:

<div id="adiv"></div>

    Теперь для доступа к объекту "adiv" нужно использовать следующий синтаксис:

adiv.style

Свойства объекта style
    Объект style обладает многими свойствами, манипулируя которыми можно динамически изменять внешний вид элемента. Сейчас я покажу некоторые из них:
backgroundColor
Фоновый цвет элемента
backgroundImage
Фоновый рисунок элемента
color
Цвет элемента
position
Тип положения элемента. Может принимать значения "absolute" (абсолютное) и "relative" (относительное)
pixelWidth
Ширина элемента
pixelHeight
Высота элемента
pixelLeft
Положение элемента по координате x
pixelTop
Положение элемента по координате y
    Приведенный выше перечень свойств далеко не полон. Он содержит лишь наиболее употребимые из них. Основной синтаксис управления свойствами стиля совершенно одинаков для всех свойств, и чуть позже я его продемонстрирую. Воздействуя на эти свойства можно изменять вид и стиль большинства элементов HTML (в отличие от единственного тега <layer> в Netscape)!
    Приведу простой пример. Текст под этим абзацем изменяет цвет, если навести на него мышью:

Наведите сюда мышью

А вот исходный код этого примера:

<span id="название" onMouseover="название.style.color='red'" onMouseout="название.style.color='black'">Наведите сюда мышью</span>

Обратите внимание, как я менял цвет текста:

название.style.color='red'

    Сначала я ввел обозначение (id) элемента. Затем, через объект style и, наконец, через свойство стиля color я смог изменить цвет текста по требованию!
    Все свойства стиля можно считывать и записывать, и синтаксис доступа к ним совершенно одинаков: обозначение элемента->объект style->свойство.
    А вот еще пример, который увеличивает рисунок при наведении на него мышью и возвращает ему прежний размер, когда мышь убирают:

<img id="aimage" src="piza.gif" onMouseover="enlarge()" onMouseout="revertback()">

<script language="JavaScript1.2">
function enlarge(){
aimage.style.pixelWidth=164
aimage.style.pixelHeight=202
}

function revertback(){
aimage.style.pixelWidth=82
aimage.style.pixelHeight=101
}
</script>

    Да, я понимаю, что это не самый полезный в мире пример, но он достаточно хорошо иллюстрирует работу DHTML. Рисунок изменяет размеры по требованию, и при этом не приходится перезагружать страницу. Одним лишь JavaScript такого никогда не получишь.

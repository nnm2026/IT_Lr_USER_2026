< теги >
заключение 		 
<TABLE>...</TABLE>
Тег TABLE открывает и закрывает таблицу.
WIDTH="..."
Атрибут width определяет ширину таблицы в пикселях или процентах.
BORDER="..."
Атрибут border определяет ширину внешней рамки. При значении равном нулю рамка не видна (значение по умолчанию).
BGCOLOR="..."
Атирибут bgcolor определяет цвет всей таблицы. Можно использовать имена цветов или их шестнадцатеричные значения.
CELLPADDING="..."
Атрибут cellpadding определяет величину промежутка между ячейками. По умолчание значение равно трем пикселям.
CELLSPACING="..."
Атрибут cellspacing опредляет величину свободного пространства между границей ячейки и ее содержимым. По умолчанию значение равно двум пикселям.
VALIGN="..."
Атрибут VALIGN определяет выравнивание текста в ячейке по вертикали. Может выравнивать по верху, по середине и по низу. Значение по умолчанию: по середине.

<TR>...</TR>
Тег TR открывает и закрывает строку таблицы.
ALIGN="..."
С помощью атрибута ALIGN содержимое ячейки выравнивается по левому краю, по середине или по правому краю. Значение по умолчанию - по левому краю. Переопределяет выравнивание, заданное для всей таблицы.
VALIGN="..."
С помощью атрибута VALIGN содержимое ячейки выравнивается по вертикали. Может принимать значения: по верху, по низу и по середине. По умолчанию выравнивает по середине. Переопределяет выравнивание, заданное для всей таблицы.
BGCOLOR="..."
Атрибут bgcolor определяет цвет отдельной строки. Можно использовать имена цветов или их шестнадцатеричные значения. Переопределяет цвет, заданный для всей таблицы.

<TD>...</TD>
Тег TD открывает и закрывает ячейку. Содержимое ячейки может располагаться только между этими двумя тегами.
WIDTH="..."
Атрибут width определяет ширину ячейки в пикселях или процентах.
BGCOLOR="..."
Атрибут bgcolor определяет цвет отдельной ячейки. Можно использовать имена цветов или их шестнадцатеричные значения. Переопределяет цвет, заданный для таблицы и строки.
ALIGN="..."
С помощью атрибута ALIGN содержимое ячейки выравнивается по левому краю, по середине или по правому краю. Значение по умолчанию - по левому краю. Переопределяет выравнивание, заданное для таблицы и строки.
VALIGN="..."
С помощью атрибута VALIGN содержимое ячейки выравнивается по вертикали. Может принимать значения: по верху, по низу и по середине. По умолчанию выравнивает по середине. Переопределяет выравнивание, заданное для таблицы и строки.
COLSPAN="..."
Этот атрибут позволяет одной ячейке занять два или более столбцов в таблице.
ROWSPAN="..."
Этот атрибут позволяет одной ячейке занять две или более строки в таблице.

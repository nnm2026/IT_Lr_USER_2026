заключение 		      Когда вы хотите начать текст с новой строчки, вы обычно нажимаете клавишу [Enter]. В текстовых процессорах это называется жестким переносом строки. Курсор переходит в следующую строку, и вы продолжаете ввод текста. Можете попробовать сделать то же самое на своей веб странице.
Это
курс
HTML
Однако то, что вы увидите, будет выглядеть следующим образом:

Это курс HTML.

Переносы строк
    HTML автоматически не переносит текст на новую строку. Он просто игнорирует переносы строк, до тех пор, пока текст не достигнет края окна браузера. На первый взгляд это может показаться странным. На самом же деле это сделано с определенным намерением. Окно браузера может иметь разные размеры. Шрифты тоже бывают разных размеров. Если вы пишите в широко открытом окне, а потом просматриваете этот текст в узком окне, это иногда приводит к совершенно непредсказуемым результатам. Типа чередующихся коротких и длинных строк.
    Создатели HTML это учли. Браузер обрывает строку только у края окна, или когда встречает специальный тег, который говорит ему, что здесь необходимо перейти на новую строку. Для этого используется простой тег <BR> или перенос строки. Если бы вы захотели, чтобы текст выглядел, как показано выше, нужно бы было сделать следующее:

Это<BR>
курс<BR>
HTML<BR>

    HTML совершенно не обращает внимания на переносы строк. Пока вы пользуетесь правильными тегами, можете располагать текст, как угодно. Для браузера это не играет никакой роли. Вы даже можете создать целую страницу из одной строки. Она будет выглядеть в вашем браузере точно так же.

    Это<BR>курс<BR>HTML.<BR>
Удобочитаемый код
    Для небольшого фрагмента HTML это вполне приемлемо, но написание целых страниц в таком стиле - чистой воды мазохизм. Такой код читать невозможно. Старайтесь, чтобы код выглядел похожим на ваши страницы. Вставляя тег <BR>,м делайте перенос строки в редакторе.

    <P>Это абзац.</P>

Абзацы
       Если вы хотите пропустить целую строку, тег BR не всегда помогает. Даже если их вставить дюжину. Для этой цели служит другой тег. Тег абзаца: <P>. Он пропускает одну строку и начинает текст со следующей. Хотя, строго говоря, этого не требуется, рекомендуется использовать закрывающий тег абзаца </P>. Если этого не делать, то могут возникнуть проблемы при последующем использовании таблиц стилей.

Поля
    Без полей текст выглядит не очень привлекательным. К тому же его труднее читать. Поля создаются с помощью тега <BLOCKQUOTE>. При этом текст будет иметь отступы с обеих сторон. До и после этих тегов вы получаете пустую строку.
    Если вы хотите, чтобы текст имел отступы только с левой стороны, можно использовать тег <UL>. С помощью этого тега можно сделать левое поле шире правого. Следующее сочетание тегов можно использовать для создания фона с непрервыной боковой полосой.

<BLOCKQUOTE>
<UL>
<UL>
Здесь расположите свой текст.
</UL>
</UL>
</BLOCKQUOTE>
Можете посмотреть, как такая страница выглядит, и найти там дополнительные советы.

Табличная разметка
    Создать страницу, похожую на страницы этого сайта несколько труднее, для этого необходимо познакомиться с тегом TABLE. Думаю, что для начинающих это слишком сложно. Но если вы хотите увидеть, как это было сделано, посмотрите на страницу посвященную компоновке страниц с помощью таблиц. Если хотите научиться использовать таблицы для создания страниц, ознакомьтесь с курсом по использованию тега TABLE.

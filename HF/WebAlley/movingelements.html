  Перемещение элементов
    Если вам нравится работать с анимацией, то радуйтесь - с появлением DHTML можно заниматься ею прямо на web страницах! Можно, например, создать объект, свободно парящий по всему экрану. В Netscape это достигается изменением атрибутов left и top тега <layer>. В IE 4 тот же эффект получается при изменении свойств pixelLeft и pixelTop объекта style.

Движущиеся элементы в NS 4
    Вы еще не забыли, что слои обладают свойствами left и top, определяющими их смещение от левого верхнего угла документа? Отлично. Теперь с помощью несложной арифметики и пары строчек скрипта мы можем изменять эти свойства, и слой придет в движение! Приведенный ниже пример изменяет свойство left, в результате, после нажатия кнопки, слой движется горизонтально.

<layer name="space" left=35>
<img src="TN00018A.gif">
</layer>
<script>
function moving(){
if (document.space.left<1000)
document.space.left+=5
moveid=setTimeout("moving()",50)
}
function come_back(){
clearTimeout(moveid)
document.space.left=35
}
</script>

<form>
<input type="button" value="Поехали" onClick="moving()">
<input type="button" value="Назад" onClick="come_back()">
</form>

    Видите, все, что я делал, это добавлял "пробелы" к свойству left, чтобы заставить слой двигаться, и возвращал свойству исходное значение, когда хотел вернуть слой назад.

Движущиеся элементы в IE 4
    Между прочим, как только NS и IE договорятся по поводу реализации DHTML, я сразу же перестану писать по две версии всего на свете (просто хочется немного поворчать). Перемещение элемента в IE 4 сводится, в общих чертах, к заключению его в позиционированный span или div, и затем к изменению свойств pixelLeft и pixelTop. Может, с виду, это и сложно, но на самом деле проще простого:

<div id="spaceship" style="position:relative">
<img src="TN00018A.gif">
</div>
<script>
function moving2(){
if (spaceship.style.pixelLeft<1000)
spaceship.style.pixelLeft+=5
moveid2=setTimeout("moving2()",50)
}
function come_back2(){
clearTimeout(moveid2)
spaceship.style.pixelLeft=0
}
</script>

<form>
<input type="button" value="Поехали" onClick="moving2()">
<input type="button" value="Назад" onClick="come_back2()">
</form>

    Сначала я определил внешний <div> по имени "spaceship", как имеющий относительную позицию. Это делает элемент перемещаемым (можно, также определить позицию, как абсолютную). Затем, изменением свойства pixelLeft объекта style, элемент приводится в движение.

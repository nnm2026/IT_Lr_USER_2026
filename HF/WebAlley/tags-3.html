<FORM>...</FORM>
Начинает и заканчивает html форму.
ACTION="..."
Говорит форме, куда посылать данные: по адресу e-mail, в программу cgi или в javascript
METHOD="..." (GET или POST)
Get передает данные в виде адреса интернет (метод по умолчанию), post передает их отдельно
<INPUT>
Поле формы, которое может содержать данные.
TYPE="..."
Указывает тип поля, может принимать следующие значения:
- submit: кнопка, передает форму
- reset: кнопка, сбрасывает форму в исходное состояние
- text: поле для ввода текста
- hidden: скрытое поле
- password: то же, что и текст, но отображает звездочки
- button: обычная кнопка, работает только с javascript
- checkbox: переключатель, используемый для ответов да/нет
- radio: селектор, используемый для выбора одного из нескольких вариантов, все элементы набора должны иметь одинаковые имена
- image: может содержать картинку, действует, как кнопка submit
NAME="..."
Определяет имя переменной, производимой полем ввода
VALUE="..."
Определяет значение поля ввода по умолчанию
SIZE="..."
Определяет размер текстового поля или пароля
MAXLENGTH="..."
Определяет максимальное число символов, которое можно ввести в текстовое поле или в поле пароля
SRC="..."
Содержит адрес рисунка для поля ввода типа image
CHECKED
Выбирает поле селектора или переключателя
<SELECT>...</SELECT>
Начинает и заканчивает выпадающий список
NAME="..."
Определяет имя переменной, производимой выпадающим списком
<OPTION>...</OPTION>
Определяет элемент списка, закрывающий тег не обязателен
VALUE="..."
Может содержать значение элемента списка, нужен только для указания значения, отличного от названия элемента списка
SELECTED
Выбирает вариант по умолчанию. Если не указан, выбирается первый элемент списка
<TEXTAREA>...</TEXTAREA>
Создает окно для ввода нескольких строк текста, между тегами можно поместить текст по умолчанию
NAME="..."
Определяет имя переменной, производимой окном
COLS="..."
Определяет ширину окна
ROWS="..."
Определяет высоту окна
<PRE>...</PRE>
Форма стандартного вида, показывает текст точно так, как он был введен в коде html, никакие дополнительные теги форматирования не нужны. Бывает полезен в сложных формах.

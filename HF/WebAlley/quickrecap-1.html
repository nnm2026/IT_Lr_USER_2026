  • Фреймы создаются с помощью тегов FRAMESET. Этот тег заменяет тег BODY обычной страницы.
  • Количество и позиции фреймов устанавливаются с помощью атрибутов ROWS и COLS. Размер указывается в пикселях или процентах, разделенных запятыми. Звездочку можно использовать для захвата всего оставшегося места. Если сумма всех указанных размеров на укладывается в окно, окно сжимается.
  • Набор фреймов содержит одну или несколько обычных веб страниц, определенных с помощью тега FRAME.
  • Фреймы имеют широкие граничные линии, которые можно отключить, установив значение атрибутов FRAMEBORDER, BORDER и FRAMESPACING равными нулю.
  • По умолчанию фреймы имеют поля, которые можно убрать, установив значение атрибутов MARGINWIDTH и MARGINHEIGTH равными нулю.
  • Если размер страницы больше, чем размер окна, то появляются полосы прокрутки. Их можно удалить, установив значение атрибута SCROLLING равным NO.
  • Ссылки в одном фрейме могут открывать страницы в другом фрейме. Ссылка должна содержать атрибут TARGET, а фреймам необходимо присвоить имена с помощью атрибута NAME. Существуют зарезервированные имена, которые используются для специальных целей.
  • Браузеры, которые не поддерживают фреймы, могут открывать страницы, заключенные между тегами NOFRAMES.

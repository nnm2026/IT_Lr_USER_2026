заключение 		  Теги
    Теги всегда располагаются между скобками "меньше чем" (<) и "больше чем" (>). Большинство тегов имеют закрывающий тег с наклонной чертой (со слешем). Некоторые теги могут использоваться с атрибутами, которые влияют на их поведение. Значения атрибутов заключаются в двойные кавычки. Теги всегда как бы обнимают друг друга. Используйте для тегов верхний регистр.
    <TAG>
    <TAG>...</TAG>
    <TAG ATTRIBUTE>...</TAG>
    <TAG ATTRIBUTE="...">...</TAG>
    <A><B>...</B></A> правильно
    <A><B>...</A></B> не правильно
Простая веб страница
    Тег HTML начинает и заканчивает страницу. Секция HEAD содержит заглавие (TITLE) страницы, которое появляется в верхней части окна браузера. Между тегами BODY размещается текст страницы. Все эти теги используются на странице только один раз. Все другие теги можно использовать только внутри тега BODY.
    <HTML>
    <HEAD>
    <TITLE>Здесь поместите заглавие страницы</TITLE>
    </HEAD>
    <BODY>
    Здесь поместите текст
    </BODY>
    </HTML>
Текст
    Текст может быть выделен с помощью тега B, сделан наклонным с помощью тега I, и подчеркнутым с помощью тега U. Эти теги можно комбинировать.
    <B>выделенный</B>
    <I>наклонный</I>
    <U>подчеркнутый</U>
Заголовок
    Заголовки создаются с помощью тега Hn, где n = 1 наибольший размер шрифта, n = 6 наименьший размер шрифта.
    <H1>Огромный</H1>
    <H2>Большой</H2>
    <H3>Нормальный</H3>
    <H4>Маленький</H4>
    <H5>Еще меньше</H5>
    <H6>Очень маленький</H6>
Переносы
    Переносы строк осуществляются с помощью тега BR, переносы абзацев - с помощью тега P.
    <BR> перенос строки
    <P> абзац
Поля
    Отступ слева делается с помощью тега UL. Тег BLOCKQUOTE создает отступы с обеих сторон. Оба тега добавляют сверху и снизу пустую строку. Комбинация этих тегов может быть использована для создания простых полей.
    <BLOCKQUOTE>
    <UL>
    <UL>
    Текст.
    </UL>
    </UL>
    </BLOCKQUOTE>
Рисунки
   Рисунок можно добавить с помощью тега IMG. Рисунок это отдельный файл, который вызывается с помощью атрибута SRC. Атрибуты WIDTH и HEIGHT определяют размер картинки и позволяют странице загружаться быстрее. Атрибут ALT описывает рисунок, а атрибут BORDER заключает рисунок в рамку. Используйте только GIF или JPEG файлы.
    <IMG SRC="файл" WIDTH="размер" HEIGHT="размер" BORDER="0" ALT="описание">
Фон
    Фон страницы задается с помощью атрибута BGCOLOR тега BODY. Атрибут BACKGROUND создает фон в виде повторяющегося рисунка. Используйте только стандартные цвета. Используйте цвет фона похожий на цвет рисунков. Этот атрибут используется на странице только один раз.
    <BODY BGCOLOR="цвет" BACKGROUND="рисунок">
    Ваш текст здесь
    </BODY>
Цвет текста
    Общий цвет текста может быть изменен с помощью атрибута TEXT тега BODY, атрибута LINK для ссылок, атрибута VLINK для ссылок, которые уже посещали и атрибута ALINK для активных ссылок. И конечно используйте только стандартные цвета. Эти атрибуты используются на странице один раз.
    <BODY BGCOLOR="цвет" TEXT="цвет" LINK="цвет" VLINK="цвет" ALINK="цвет">
    Ваш текст здесь
    </BODY>
Гиперссылки
    Для соединения веб страниц друг с другом используются гиперссылки. Для этого служит тег A (anchor или якорь). Атрибут HREF определяет имя файла, на который вы делаете ссылку. Используйте префикс 'http://' если вы делаете ссылку на другой сервер. Вместо текста можно использовать для ссылки рисунок. Это делается с помощью тега IMG. Префикс 'mailto:' создает ссылку на адрес электронной почты.
    <A HREF="файл">описание</A>
    <A HREF="файл"><IMG SRC="файл"></A>
    <A HREF="mailto:email">email</A>
Последние заметки
   Веб страницы сохраняются в виде простых текстовых файлов с расширением .html. Используйте только нижний регистр для имен файлов, чтобы избежать проблем на UNIX серверах. Используйте для создания страниц простой текстовый редактор.
